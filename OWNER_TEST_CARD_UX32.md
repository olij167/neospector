# UX32 Owner Acceptance · Zorin OS Xorg

1. Start the new ZIP independently. Confirm the title includes UX32 and your existing files/profile remain available. The old Creative Controls window must not open.
2. Click top **Transition** selector; Effects should open on **TRANSITION** with the full selector label, A/B/Transition/Output rack controls and no missing buttons.
3. Add **Reveal Field**, **Grain** and **Invert**. Drag Angle/Softness/Amount. Crossfade A→B and observe the authored reveal and processing while midway, with original A/B images unchanged at either endpoint. Disable the Transition rack: A/B must stay unaffected.
4. Select two effects; **Group**, edit the group and promoted parameters, reorder and ungroup. Save/reopen a project. Undo and redo the grouped change. Echo / Frame Blend must be absent from Transition Library but present in Output and A/B libraries.
5. In each rack, click **Options ▾** immediately below Random Rack / Mutate. Edit Count, Range %, Mutate %, Seed and Selected. Save and run Random / Mutate; confirm existing locks, selection and rack boundaries. Collapse options; there must be no lingering blank status row. Resize to 1024–1350px to check wrapping.
6. In AUDIO → MIX select **＋**. The left workbench must show **Media & Sources → Sources**, not a dropdown. Sources must not start on mere discovery. Check only engaged sources have faders.
7. Check native and styled contextual menus at desktop edges and over a right-aligned panel: open, click outside to close, Escape, and toggle the same launcher twice. The system-owned file chooser/combobox still works.
8. Regressions: camera and mic toggles, A/B/Audio queue stop/repeat/reorder, grouped effects on ordinary racks, audio reaction, recording, export, saved projects and source relinking.

Release is a Linux Xorg evaluation candidate, not hardware-certified. Confirm actual audio devices and exports on the owner workstation before final acceptance.
