# UX35 owner acceptance — Zorin Linux Xorg

Use the installed UX35 archive. Keep UX34 installed separately until accepted.

1. Open Welcome. Check OmN-e → Neospector → by Pungent Funk, functional recent projects, new/open/import/example, Theme Studio, Support/Check Updates. Verify Welcome can reopen from File.
2. Open Preferences from Welcome and File. Visit General, Devices & Media, Output, Recording, Appearance, Updates & Support. Check File → Output Settings and Recording Settings open those pages in the SAME window.
3. Change default camera/microphone without activating capture. Set default media folder, enable optional auto-import, create a new EMPTY project and verify supported top-level media import once. Confirm unsupported files and nested media are skipped; confirm disabled option doesn't import.
4. Open Effects → Transition and test a multi-row Iris/Pixellated/Glitch module. All sliders/fields, last parameter row, and bottom Split/Lock/Remove controls should remain visible. Add many modules to check rack scroll.
5. Try Theme Studio via Welcome and File. Check theme changes and saved preferences survive app restart. Confirm clicking outside menus, dismissal and keyboard remain usable.
6. Check the real camera, mic, application audio, recording, playback, and export remain working from UX34; capture never starts from Welcome/Preferences.

**Known limitation:** Check Updates opens the website, not a checked software version feed. Hardware/recording/export, responsiveness and physical UI acceptance pending.
