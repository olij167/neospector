# UX37 — Owner acceptance (Zorin OS)

1. Launch from the fresh ZIP; open Welcome and select each of the six Funk themes. Verify the **entire open Welcome** recolours immediately (background, heading and controls), and the instrument reflects the same theme.
2. Open Preferences → Appearance while Welcome is still open. Select another theme; the Welcome selector and colours should preview together. Close Preferences **without applying** and confirm both return to the committed theme.
3. From Welcome, select another theme while Appearance Preferences is open. Close Preferences; the Welcome selection should **remain applied** and survive relaunch.
4. In Preferences → Appearance adjust a colour; Apply must commit a separate custom theme rather than overwrite a built-in one. Check all six published themes can still be selected unmodified.
5. Open Preferences → Output; confirm project name, canvas preset, width, height, fps, minimum duration, background colour and preview quality all appear *inside that page*. Changing these should update the current project and not open another window.
6. Test File → Canvas/Sequence Settings and File → Output Settings; both should open the Output page in the same Preferences window. Test File → Recording Settings similarly.
7. Resize Preferences smaller; confirm Close and Apply stay visible and functional. Confirm Welcome has only one Preferences button, with no duplicate Output/Recording shortcuts.
8. Test normal import, module editing, camera/mic toggles, transition rendering and export using your known-good UX36 project. Do not treat virtual display tests as proof of hardware capture or recording.

Report any mismatched theme names/colours, lost saved settings, dialogs reappearing, or clipped controls, along with screenshots/logs. UX36 is the rollback release.
