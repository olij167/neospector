# UX39 Owner Acceptance — Zorin OS

Start in a separate extracted UX39 directory; UX38 should remain installed as a rollback.

1. **Rack responsiveness:** Add 6–12 mixed single modules and groups on A, B, Output and Transition. Drag multiple parameter sliders quickly, then slowly. Check immediate thumb/value tracking; no pauses, flicker, partially replaced cards, or spontaneous module reordering.
2. **During live playback:** Run camera/video sources on A and B and change module parameters while crossfading. Preview frames should keep progressing, with no stalling or desynchronised audio; recording must remain uninterrupted.
3. **Undo/redo:** Drag one module value to a different value, release, Undo once then Redo. Verify the complete single gesture and exact restoration. Repeat with record-automation enabled and keyframes; do not change other racks.
4. **Groups/scroll:** Edit the last parameter of a large group, then scroll and switch racks. No disappearing parameter rows or unexpected size changes; selection persists.
5. **Peripheral workflows:** Test camera toggles, queue repeats, Media/Sources browser, audio mixer, transition rack and full recording/export. No reconfiguration of microphone when only dragging an unrelated visual slider.
6. **Idle:** Leave several racks open while stopped and during playback, monitor responsiveness, preview frame age, RAM and CPU; compare directly to UX38 on the same project and settings.
7. **Updates:** Check for updates offline and under a working network, but do **not** connect/publish the owner companion as part of this UX39 performance gate. UX38 update security model and feed path remain unchanged.

**Acceptance:** No regression in live AV continuity, project serialization or update verification. The virtual-display synthetic benchmark is not physical workstation proof. Keep UX38 as fallback.
